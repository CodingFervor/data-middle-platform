# Data Middle Platform

## English | [中文](#中文)

A data middle platform (data hub) built with Go, Gin, PostgreSQL, and Redis.

### Features
- Data source management (MySQL, PostgreSQL, MongoDB, API, CSV)
- ETL pipeline configuration and scheduling
- Data warehouse modeling
- Real-time and batch data processing
- Data quality monitoring
- Data API publishing (Data-as-a-Service)
- Metadata management
- Data lineage tracking
- Dashboard and visualization support
- Access control and data governance

### Quick Start
```bash
docker-compose up -d
go run cmd/api/main.go
```
